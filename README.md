# PPCube V2.0

## 简介

人际立方/PPCube（Person-Person Cube）是一个人物关系知识图谱，用于记录人物属性以及人物之间的社会关系。PPCube V2.0 的数据来自 Wikidata、Wikipedia、DBpedia 和 YAGO，包含中文和英文数据。数据经过人物实体筛选、字段统一、人物关系筛选、关系类型统一和质量检查，最终整理为人物节点、人物属性和人际关系三类数据。

PPCube V1 主要包含中文数据，PPCube V2.0 在数据来源、数据规模和类型覆盖方面进行了扩展。当前全量版本 PPCube-FULL 包含 24,140,466 条人物节点记录、136,984,143 条人物属性记录和 7,720,013 条人际关系记录。PPCube-Dense 从全量数据中选取信息较丰富的核心人物，并加入与这些人物直接相连的一跳人物，包含 99,998 条人物节点记录、1,040,886 条人物属性记录和 381,244 条人际关系记录。

- 2026 年 9 月开放 PPCube-Dense V2.0 下载。

## 数据版本

| 版本 | 人物节点记录 | 人物属性记录 | 人际关系记录 |
| --- | ---: | ---: | ---: |
| PPCube-FULL | 24,140,466 | 136,984,143 | 7,720,013 |
| PPCube-Dense | 99,998 | 1,040,886 | 381,244 |

PPCube-FULL 按数据来源分别保存。当前版本尚未将不同来源中表示同一人物的节点合并，因此同一人物可能在多个来源中分别出现。人际关系只连接同一来源中的人物节点。

## 人物 ID

`entity_id` 是 PPCube 统一使用的人物编号。取值为 `PID_` 加 12 位数字，例如 `PID_000000000001`。编号本身不表示人物的数据来源。

## 人物属性类型与人际关系类型

| 版本 | 人物属性类型数量 | 人际关系类型数量 |
| --- | ---: | ---: |
| PPCube-FULL | 41 | 63 |
| PPCube-Dense | 41 | 55 |

人物属性数据使用 `AID_四位数字` 形式的属性 ID，人际关系数据使用 `RID_四位数字` 形式的关系 ID。每种属性和关系的 ID、英文名称、数据类型及含义分别记录在各版本目录下的 `schema/attribute_types.csv` 和 `schema/relation_types.csv` 中。


## PPCube-Dense V2.0

PPCube-Dense 是人物信息较丰富的子集，保留了属性和关系记录较多的人物，以及与这些人物直接关联的人物。

人物信息密度由该人物拥有的属性记录数、关系入边数和关系出边数共同计算。为减少不同数据源规模差异带来的影响，先在各数据源内部排序，再按来源规模选取信息密度较高的核心人物并进行一跳扩展。当前版本包括 4,371 个核心人物和 95,627 个一跳扩展人物，共 99,998 个人物节点。

### 数据规模

- 人物节点记录：99,998 条
- 人物属性记录：1,040,886 条
- 人际关系记录：381,244 条

PPCube-Dense 不包含尚未统一的 Others 数据，也不包含待确认或关系端点缺失的人际关系。

### 文件

- `data/person_nodes.csv`：人物节点数据文件。
- `data/person_attributes_part_*.csv`：人物属性数据分片，共 3 个文件，各分片表头相同。
- `data/person_relations.csv`：人际关系数据文件。
- `data/README.md`：三类数据的字段说明。
- `schema/schema.json`：供程序读取的完整属性和关系定义。
- `schema/attribute_types.csv`：属性 ID、英文名称、数据类型和含义。
- `schema/relation_types.csv`：关系 ID、英文名称、数据类型和含义。
- `statistics/source_statistics.csv`：各来源的人物、属性和关系数量。
- `statistics/attribute_statistics.csv`：各来源中每种属性的记录数量。
- `statistics/relation_statistics.csv`：各来源中每种关系的记录数量。
- `statistics/README.md`：统计文件的字段说明。

公开数据统一使用 CSV。人物属性的 3 个分片具有相同表头，合并使用时只保留一次表头。各数据字段的具体含义见 `data/README.md`。
